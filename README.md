# React Forms

A simple React form application for collecting job application details such as personal information, contact details, skills, resume upload, and social links.

## Features

- Personal details form
- Contact and email validation
- Gender selection
- Skill/domain selection
- Resume file upload
- LinkedIn and GitHub URL inputs
- Short bio / about section
- Submit and reset actions

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open the app in your browser at the local URL shown in the terminal.

## Build

To create a production build:

```bash
npm run build
```
