# React Job Application Form

A clean and responsive React application designed to collect job application details in a professional, user-friendly format.

## Overview

This project is a form-based web app built with React and Vite. It allows users to enter personal information, contact details, job-related preferences, and profile links while presenting a polished and structured user experience.

This project demonstrates core front-end development skills including state management, form handling, responsive layout design, and UI logic for real-world applications.

## Key Features

- Personal details form with first name, last name, and email
- Contact number input
- Gender selection
- Domain/skill selection
- Resume upload field
- LinkedIn and GitHub profile URL inputs
- About section for candidate introduction
- Submit and reset actions
- Clean, modern form styling

## Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/mallepalliharshavardhan/React-Forms.git
   ```

2. Navigate to the project folder
   ```bash
   cd React-Forms
   ```

3. Install dependencies
   ```bash
   npm install
   ```

4. Start the development server
   ```bash
   npm run dev
   ```

5. Open the local URL shown in the terminal in your browser.

## Build for Production

```bash
npm run build
```
